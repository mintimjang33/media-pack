## 1. ★소재 게이트 — 여기서 걸러야 한다

벤치마크 채널이 **36편을 태워서** 증명한 실패 포맷이 있다(중앙값 3.1만 vs 58만, **18.7배**).
소재 선정이 성패의 대부분이다.

### 통과 3조건 (전부 만족해야 함)

| # | 조건 | 확인 질문 |
|---|---|---|
| 1 | **친숙한 대상** | 설명 없이 이름만 대도 아는가? |
| 2 | **상식적 해법이 실제로 실패** | "그냥 ~하면 되잖아"가 왜 안 되는지 물리적 이유가 있는가? |
| 3 | **실제 해법이 직관에 반함** | "막는 대신 ~한다" 형태로 한 줄이 나오는가? |

### 추가 가점
- 수치로 증명 가능 (치수·톤수·연도·개수)
- **지금도 작동 중** ("지금도 ~하고 있습니다")
- 일상 단위 환산 가능 (아파트 N층 / 축구장 N개)

### ⛔ 실격 조건
- **"만약 당신이 ~라면"** 가정형 — 검증된 실패 포맷
- **how-to 레시피** — 갈등 구조가 없음
- 반전이 없음 (그냥 신기한 사실)
- 상식적 해법이 실제로 통함

### 판정 예시

| 소재 | 판정 | 사유 |
|---|---|---|
| 만두 주름 | ✅ | 두껍게=속이 안 익음 → 접어서 겹을 만든다 |
| 김치볶음밥 | ❌ | 반전 없음 |
| 층간소음 | ✅ | 두껍게=안 잡힘 → 진동 경로를 끊는다 |
| 에어프라이어 | ✅ | 기름 없이 튀김? → 대류 속도로 대체 |
| "만약 10일 안에 방벽을" | ⛔ | 가정형 |

## 2. ★95초 대본 템플릿 — 8구간

1위작(490만·97초) 실측 배분. **초는 가이드, 비율이 계약.**

| # | 구간 | % | 초(95s) | 내용 |
|---|---|---|---|---|
| 1 | **훅** | 9 | 0~9 | 모순 제시 → 정체 공개 → **인공물 선언** |
| 2 | **과거/문제** | 15 | 9~23 | 원래 어땠는지, 뭐가 문제였는지 |
| 3 | **1차 해법** | 16 | 23~38 | **수치 폭격** |
| 4 | **★새 문제** | 15 | 38~52 | "그런데 ~했더니 이번엔" |
| 5 | **★반박 선점** | 6 | 52~58 | "그럼 ~하면 되지 않냐고요?" + 즉답 |
| 6 | **★발상 전환** | 10 | 58~68 | 핵심 명제 한 줄 |
| 7 | **작동 원리** | 14 | 68~81 | 메커니즘 + 수치 |
| 8 | **클로징** | 15 | 81~95 | 현재 연결 + 수미상관 |

### 고정 문형 4종 (그대로 채워 쓴다)

```
훅      : "여기 {장소}에는 {A}인데 {A가 아닌} {대상}이 있습니다."
          "…{정체 공개}죠. 그런데 이건 {저절로 그런 게} 아니라 {인공/의도}입니다."

반박선점: "그럼 {상식적 해법}하면 되지 않냐고요?"
          "{그러면 벌어지는 일}."

전환    : "그래서 발상을 뒤집습니다. {상식} 말고 {역발상}한 겁니다."

클로징  : "우리가 아는 그 {대상}은 이렇게 {탄생한/만들어진} 겁니다."
```

### 엔진 = 문제 → 해법 → **새 문제** → 해법 사슬
각 해법이 새 문제를 낳게 짠다. 이게 이탈을 막는다. 최소 1회, 길면 2회 반복.

### 문체 규칙
- 구어체 존댓말 — `~거든요` `~죠` `~고요` `~습니다`
- **짧은 단문.** 복문 금지
- 수치는 **일상 단위 환산 병기** — "8.5톤 트럭 1300만 대분" / "아파트 30층"
- **반박 선점 편당 1~2회**
- ★분량: **6.8자/초** (벤치마크 실측) → 95초 ≈ **650자**. 450~550자는 28% 얇다

## 3. 제목 6패턴

| 패턴 | 틀 |
|---|---|
| A인데 A가 아니다 | `{대상}이 {A}가 아니라 {B}인 이유` |
| 사실은 ~ 위에 | `{대상}, 사실은 {반전} 위에 {있습니다}` |
| 보이는 것 ≠ 실제 | `{대상}은 {A}해 보이지만 사실 {A}하지 않습니다` |
| **일부러** | `{대상}을 일부러 {비상식적 처리}한 이유` |
| 진짜 이유 | `{상식적 조치}해도 {문제}가 안 잡히는 진짜 이유` |
| 모순 수치 | `{조건A}인데 {모순되는 사실B}` |

**필수 성분**: 구체 수치 · 친숙한 고유명사 · `~인 이유` / `~한 방법` 어미

## 4. 시각 규격

### 4-1. 레이어 구조

```
① 베이스   3D 디오라마 / 단면 컷어웨이 — 회색 격자 바닥, 등각 시점, 모형 질감
② 빨간 오버레이 (단일 색)
     · 치수선 + 숫자 (98m, GAP: 12M)
     · 영문 라벨 (NANJIDO MOUND, TOLERANCE BAND)
     · 흐름 화살표 / 굵은 X / 게이지 / 데이터 박스
③ ★큰 한글 챕터 라벨   (1986년 · 갈수기 · 장마철) — 쇼츠 전용
④ 하단 자막   나레이션 번인
```

★ **영문 라벨 = 권위 / 한글 자막 = 이해**. 이 이중 구조가 시그니처다.

### 4-2. 컷 리듬
**약 1초에 1컷.** 95초에 80~100컷.
→ 컷마다 새 이미지를 만들 수 없다. **한 장면을 만들고 카메라·오버레이로 쪼갠다.**

### 4-3. 규격
9:16 · 1080×1920 · H.264 · AAC 48kHz

### 4-4. 우리 스택 배선

| 레이어 | 담당 | 상태 |
|---|---|---|
| 베이스 | Krea 2 (단면 1~5장) | 로컬·무료 |
| 오버레이·라벨·자막 | **Remotion** | 기존 배선 재사용 — 이미지 모델보다 **정확** |
| 카메라 무브 | Remotion | 기존 |
| 나레이션 | Qwen3 클론 TTS | 기존 |

**병목**: 같은 대상을 여러 각도로 해부하는 3D.
→ 파일럿은 **Krea 2 단면 + Remotion 레이어 분리**, 격상은 **Blender 스크립팅**.

## 5. 팩트체크 규율

이 장르의 신뢰는 **수치**에서 나온다. 벤치마크 채널도 설명글에
`반박·정정 환영합니다. 근거 자료와 함께 댓글로 남겨주세요.` 를 상시 붙인다.

- 모든 수치는 **1차 출처** 확인 (공공기관 보고서·공시·논문·특허)
- 출처 없는 수치는 **쓰지 않는다**
- 대본에 `[근거: URL]` 주석을 남기고 렌더 전 제거
- 위 문구를 설명글에 상시 삽입

## 6. 설명글·발행

```
1. 제목 재진술
2. 배경 — "원래 ~였습니다"
3. 문제 — "그런데 ~"
4. 해법 반전 — "~ 대신 ~"
5. 수치 나열
6. ★반박·정정 환영합니다. 근거 자료와 함께 댓글로 남겨주세요.
7. 해시태그 — #지식채널 + 소재 태그
```

**발행 주기**: 벤치마크는 거의 매일. 우리는 소재 게이트 통과분만.
**롱폼 재활용**: 히트한 쇼츠를 5분 확장 (벤치마크가 실제로 하는 방식 — 소재 재사용)
